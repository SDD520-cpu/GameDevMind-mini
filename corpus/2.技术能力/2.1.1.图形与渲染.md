# 图形与渲染

- **DrawCall**：CPU 向 GPU 发起的一次绘制提交；次数过多会让驱动层成为瓶颈。
- **合批**：把使用相同材质的对象合并提交，前提是材质与渲染状态可共享。
- **材质**切换会打断合批，所以打包图集、统一 shader 变体往往比减面数更有效。
- 排查**卡顿**先分辨是 CPU  bound 还是 GPU bound，再看提交次数、三角面与填充率。
- 诊断练习里给出的数字只是假设，必须用自己的帧捕获数据复核。
