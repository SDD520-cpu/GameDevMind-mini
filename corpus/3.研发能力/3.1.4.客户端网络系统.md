# 客户端网络系统

- **回调隔离**：旧连接的回调必须失效，否则重连后会把过期响应写进新状态。
- **重连恢复**：先拉取权威快照，再补增量；补流起点要用服务端确认的序号。
- **帧同步**与**状态同步**决定了本地是否允许预测，两套逻辑不要混在同一层实现。
- 请求层统一带 request id，配合**幂等**避免重发造成的重复扣减。
- 网络层只负责传输与时序，玩法状态机不应该直接读 socket。
